# Socio-Economic Indicator for German Kreise

Replication materials for the empirical sample task.

The repository contains:

- 4 processed data files used in the analysis
- Analysis script used to process the data and construct the indicator
- Final visualization of the socioeconomic indicator

The data files are processed versions of the original datasets. Basic preparation and formatting, including removing unnecessary rows and columns, was performed in Excel before the analysis.

## Workflow of the script

1. Downloads the source datasets listed in the report.
2. Performs basic data cleaning and formatting.
3. Merges the datasets at Kreis level.
4. Standardizes the socioeconomic variables.
5. Constructs the socioeconomic indicator.
6. Generates the final visualization.

Some initial data preparation was performed manually in Excel. The resulting processed files are included in the repo as well
